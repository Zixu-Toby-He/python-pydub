# python-pydub —— 基于 pydub 的音频合成工具

本项目使用 Python 的 `pydub` 和 `numpy` 库，通过简单的曲谱描述，自动生成 WAV 格式的音乐文件。代码采用中文命名，易于理解和修改，适合音乐制作入门或快速原型开发。

## 功能特点

- **曲谱转音频**：将数字简谱（如 `1, 2, 3...`）转换为对应频率的正弦波或方波声音。
- **多种音色**：提供正弦波、方波、三角波、锯齿波等基础波形，可自由组合。
- **调制音色扩展**：在 `调制音色/` 目录下尝试了振幅调制等更复杂的音色设计。
- **乐曲示例**：内置《小星星》《世上只有妈妈好》《雨刷器之歌》等经典曲目。
- **音频导出**：直接生成 `*.wav` 文件，方便播放或进一步处理。

## 依赖安装

确保已安装 Python 3.6+，然后运行：

```bash
pip install numpy pydub
```

> **注意**：`pydub` 依赖 `ffmpeg` 或 `libav` 进行音频编码/解码。请根据操作系统安装：
> - Windows：下载 [ffmpeg](https://ffmpeg.org/download.html) 并添加至 PATH。
> - macOS：`brew install ffmpeg`
> - Linux：`sudo apt install ffmpeg`

## 快速开始

以“音色”目录下的《小星星》为例：

```bash
cd pydub制作音频/音色
python 小星星.py
```

运行后会在当前目录生成 `小星星.wav`，可以直接播放。

## 自定义曲谱

曲谱使用列表表示，每个元素为一个数字（代表音高）或空字符串 `""`（表示休止符）。音高与频率的对应关系见 `音乐制作.py` 中的 `音高频率表`。

例如，C大调《小星星》的简谱：

```python
曲谱 = [
    1, 1, 5, 5, 6, 6, 5, "",
    4, 4, 3, 3, 2, 2, 1, "",
    ...
]
```

你可以修改 `音符持续时间` 和 `音符间中顿时间` 变量来调整节奏。

## 音色扩展

在 `所有乐器.py` 中，你可以自定义波形函数（输入相位 `phi`，输出振幅 `[-1,1]`），然后传入 `曲谱转化为震动(曲谱, 乐器)` 即可更换音色。

示例：
```python
import 所有乐器
乐器 = 所有乐器.方波   # 或 正弦波, 三角波, 锯齿波
震动 = 音乐制作.曲谱转化为震动(曲谱, 乐器)
```
